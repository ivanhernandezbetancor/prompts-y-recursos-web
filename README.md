## 🤖 1. Prompts Maestros para IA

<details>
<summary><b>🤖 Opción A: Integración de Librerías y Recursos de GitHub</b></summary>

> *Usa este prompt si quieres que la IA te sugiera código directo e integre librerías de código abierto dentro de tu proyecto.*

```text
Actúa como un Desarrollador Web Senior y Diseñador UI/UX experto. Yo soy diseñador web, apasionado por la causa animalista y especialista en animación. 

Necesito desarrollar y mejorar mi sitio web / portafolio integrando librerías, módulos y recursos de código abierto disponibles en repositorios de GitHub (como librerías de animación, componentes interactivos o micro-interacciones) para potenciar la experiencia visual y el impacto del proyecto.

Detalles y requisitos de desarrollo:

1. ENFOQUE DEL PROYECTO:
- Sitio web/portafolio centrado en el ámbito animalista (diseño emotivo, moderno, profesional y accesible).
- Animaciones fluidas, interactivas y ligeras que transmitan empatía (micro-interacciones al pasar el cursor, scroll animado, transiciones de tarjetas de animales/proyectos, etc.).

2. INTEGRACIÓN DE REPOSITORIOS Y LIBRERÍAS DE GITHUB:
Recomiéndame e integra en el proyecto las mejores librerías de código abierto disponibles en GitHub para:
- Animaciones e interactividad (ej. GSAP, Framer Motion, Lenis Smooth Scroll, AutoAnimate, Lottie, etc.).
- Componentes UI eficientes y responsivos.
- Efectos de scroll / entrada.

3. LO QUE NECESITO QUE HAGAS:
- Propón la integración práctica de las librerías seleccionadas.
- Explícame cómo instalar/vincular esas librerías en mi proyecto (vía npm, CDN o imports).
- Escribe el código práctico (HTML/CSS/JS o React/Tailwind según corresponda) de una sección clave (por ejemplo, la Hero Section o una Galería Interactiva de Proyectos/Causas) integrando activamente esas librerías y sus animaciones.

Comienza proponiendo el código de la primera sección animada integrando las librerías correspondientes.
